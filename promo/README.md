# 传播素材包 / Promo kit

所有素材可直接用于发帖，**优先发竖屏视频**（完播率和点击率最高）。

## 素材清单

| 文件 | 用途 |
|---|---|
| `demo-vertical.mp4` | 15 秒竖屏视频（1080×1920），抖音 / 小红书 / B站 / 视频号 / X |
| `story-1080x1920.jpg` | 竖屏封面 / 故事卡片 |
| `square-1080.jpg` | 方图，适合小红书 / 朋友圈 / Instagram |
| `social-1200x630.jpg` | 横图，适合 X / 公众号头图 / 论坛链接卡片 |
| `copy-zh.md` | 中文文案（V2EX / 知乎 / 小红书 / B站 / 微博 / 群） |
| `copy-en.md` | 英文文案（X / Reddit / HN / dev.to） |

## 链接（发帖统一用）

- 在线试用（首选，不用安装）：https://ruohan0713.github.io/dsh-theme-studio/
- GitHub：https://github.com/ruohan0713/dsh-theme-studio
- npm：https://www.npmjs.com/package/dsh-theme-studio-art
- 安装：`npx @deepseek-ai/dsh plugin --profile desktop add dsh-theme-studio-art`
- 收录：awesome-dsh-plugin PR #14848 已合并（社区目录重建后在 DSH 插件市场 / dshmarket Themes 出现）

## 发布节奏建议

1. **第 1 天**：GitHub（已完成）+ 自己朋友圈/DSH 群发一条简短图文
2. **第 2 天**：V2EX「分享创造」+ 知乎想法（带 demo 链接）
3. **第 3 天**：小红书 / B站 / 抖音（竖屏视频 + 方图）
4. **第 4 天**：X / Reddit（英文帖，带 GIF 或视频）
5. 之后每周一条使用场景/新主题预告，保持更新

## 发帖注意事项

- 一次只发 1–2 个平台，别在无关群里刷链接
- 标题不要夸大；正文说清楚「20 套主题 / 浅深双配色 / 三档清晰度 / 一键换壁纸 / MIT」
- 一定带图或视频，纯链接点击率很低
- 评论区补充安装命令和 demo 链接
